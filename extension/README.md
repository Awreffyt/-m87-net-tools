# M87 端点直连（浏览器扩展）

M87 网页版要抓的站如果有 Cookie 门禁、JS 挑战、五秒盾、登录墙，浏览器自己是能过的——
只是网页脚本跨域读不到它。这个扩展开一条本地通道：M87 让浏览器去开那一页，
浏览器自己过门禁、自己渲染，完事把最终页面交回 M87。

**一次安装，之后全自动。没有服务器、没有账号、没有第三方、地址固定。**

## 安装（1 分钟，只需要一次）

1. 下载 `m87-extension.zip`（在本目录上一级，或直接下 `extension/` 整个文件夹）
2. 解压到一个**你不会删**的位置，例如 `文档/m87-extension`
3. Chrome / Edge 地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`）
4. 右上角打开「开发者模式」
5. 点「加载已解压的扩展程序」，选中第 2 步那个文件夹
6. 回到 M87 页面刷新一次

装好后 M87 顶部会显示「直连已就绪」。之后输入任何网址点提取就行了。

## 它做什么、不做什么

- 只在你点「提取」时，在后台开一个标签页去取那一页，取完立刻关掉
- 不读取你任何本地数据、不读取其他标签页、不向外发送任何内容
- 不修改目标页面，不注入任何东西到目标站
- 全部代码就在这三个文件里，可以直接读

## 兼容

- Chrome / Edge 111+（Manifest V3）
- 首次安装后如果提示「可访问网站：点击时」，在扩展详情里改成「在所有网站上」，
  否则个别页面可能不生效（M87 页面本身不受影响）

## 卸载

`chrome://extensions` → 移除。M87 会自动退回原来的书签通道，不影响使用。
