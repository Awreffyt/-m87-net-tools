资源提取

抓取页面并拆出图片、视频、音频、链接、脚本、样式、字体与内嵌框架。点「顺藤摸瓜」可递归抓取同域内链，并深挖 CSS / JS 里的隐藏资源，最后一键打包带走。

示例
第一次用？点这里看怎么打包资源

输入页面地址后，服务端会抓取页面并解析出八类资源，相对路径会自动补全为完整地址。

勾选需要的资源，点击「打包 ZIP」，浏览器会下载一个包含全部文件的压缩包。

顺藤摸瓜：从入口页出发，按选定深度递归抓取同域内链的所有页面，同时解析每个页面的 CSS 与 JS，把里面引用的图片、字体、接口等隐藏资源一并挖出。适合对付懒加载、CSS 背景图、JS 动态拼接路径等场景。

深度挖掘：除了 HTML 本身，还会跟进外链 CSS 与 JS，从源码里还原被混淆或拼接的资源路径；同时解析内联 JSON 数据块（Next.js 的 __NEXT_DATA__、importmap）、robots.txt 里的屏蔽目录与 sitemap.xml。

暴露探测：额外探测 16 个常见的泄露路径（.env、.git/config、backup.zip、db.sql、.DS_Store 等），用来发现被误放到公网的配置、备份与源码目录。

页面预览是静态快照，脚本与外部交互已禁用，只用于查看结构。

DNS 查询

        
支持 A / AAAA / MX / TXT / NS / CNAME / SOA / CAA 记录与 IP 反查（PTR），可切换 DoH 解析器，并做多解析器一致性对比。

        看不懂记录类型？点这里
        

          
A 域名对应的 IPv4 地址，最常见。

          
AAAA 域名对应的 IPv6 地址。

          
MX 邮件服务器地址，数字越小优先级越高。

          
TXT 文本记录，常用于域名所有权验证和邮件反垃圾配置。

          
NS 这个域名由哪些 DNS 服务器负责解析。

          
CNAME 别名，把域名指向另一个域名。

          
SOA 域名的基础管理信息，包括主服务器和管理员邮箱。

          
CAA 允许哪些证书机构为该域名签发证书。

          
PTR 反向解析，用 IP 地址查对应域名。

密码破解工具箱

    
纯前端实现，全部计算在本机浏览器完成，不经过服务器、零网络请求、零依赖。
       覆盖编码/Base64 解套、古典密码、XOR 爆破、AES 解密与弱口令爆破、哈希识别。

  


  

    
    
    
    
    
  


  
  

    
Base64 是编码不是加密，任何 Base64 都能直接还原。支持标准型、URL-safe、
      缺 padding、带 data URI 前缀，以及多层嵌套自动解套。Hex、URL 编码同理。

    

      
解码 / 解套

      
粘贴可疑字符串，选一种工具或直接「自动解套」（Base64 解出的还是 Base64 就继续解）。

      
      

        
        
        
        
      

      

    

    

      
编码

      
把明文编码成 Base64 / Hex / URL 格式，便于对比验证。

      
      

        
        
        
        
      

      

    

  


  
  

    

      
ROT13 / Atbash / 摩斯电码

      
ROT13 和 Atbash 是无密钥替换密码，一键还原。摩斯码用空格分隔、斜杠分隔单词。

      
      

        
        
        
        
      

      

    

    

      
凯撒密码爆破

      
26 个位移全部列出，按英文字频自动评分排序，最可能的排在最前。

      
      

        
      

      

    

    

      
维吉尼亚密码

      
已知密钥时的解密（密钥只取字母，不区分大小写）。

      
      

        
        
      

      

        
      

      

    

  


  
  

    
XOR 加密强度完全取决于密钥。单字节密钥只有 255 种可能，暴力破解瞬间完成；
      循环密钥也能通过「密钥长度猜测 + 逐字节爆破」还原。

    

      
密文输入

      
自动识别 Hex / Base64 / 纯文本三种格式。

      

        
        
      

      
    

    

      
单字节 XOR 爆破

      
256 个候选密钥按可读性评分，列出前 20 个。

      

        
      

      

    

    

      
自动猜测循环密钥

      
用汉明距离猜密钥长度（前 3 名），再逐字节爆破。适合 repeating-key XOR。

      

        
      

      

    

    

      
已知密钥 XOR

      
密钥按 UTF-8 处理，循环使用。

      

        
        
      

      

        
      

      

    

  


  
  

    
诚实声明：AES 密钥空间是 2128 起，没有密钥时在数学上无法破解。
      本工具提供的是「已知密钥解密」和「弱口令字典爆破」（只针对密码字典里那几十个常见口令、或 CTF 里 md5(口令) 派生密钥的场景）。
      TLS/HTTPS 流量请用抓包模块看握手元数据，应用数据密文任何人（包括本工具）都解不开。

    

      
密文 / 明文输入

      
密文长度必须是 16 的倍数；解密时自动尝试 Hex / Base64 识别，也可手动指定。

哈希是单向函数，设计上不可解密，只能比对。本工具做的是「这是哪种哈希」的识别，
      给出长度、字符集、前缀特征的判断，方便你拿去正确的渠道（彩虹表 / 哈希库）查询。

    

      
哈希识别

      
支持 MD5、SHA-1/256/384/512、NTLM、bcrypt、Argon2、MD5-crypt、SHA-crypt 等。
