DNS 查询

        
支持 A / AAAA / MX / TXT / NS / CNAME / SOA / CAA 记录与 IP 反查（PTR），可切换 DoH 解析器，并做多解析器一致性对比。

        看不懂记录类型？点这里
        

          
A 域名对应的 IPv4 地址，最常见。

          
AAAA 域名对应的 IPv6 地址。

          
MX 邮件服务器地址，数字越小优先级越高。

          
TXT 文本记录，常用于域名所有权验证和邮件反垃圾配置。

          
NS 这个域名由哪些 DNS 服务器负责解析。

          
CNAME 别名，把域名指向另一个域名。

          
SOA 域名的基础管理信息，包括主服务器和管理员邮箱。

          
CAA 允许哪些证书机构为该域名签发证书。

          
PTR 反向解析，用 IP 地址查对应域名。

使用 DNS over HTTPS，结果更接近真实解析；输入 IP 会自动切换为 PTR 反向解析。
